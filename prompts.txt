## The Master Prompt Template Constraints

*(These constraints are integrated into every prompt below to guarantee a single-file output.)*

1.  **Single File Requirement:** All HTML structure, CSS styling (using the `<style>` tag), and JavaScript logic (using the `<script>` tag) must be contained within one single `index.html` file.
2.  **Functionality:** The resulting file must be fully functional and playable upon opening it in a modern web browser.
3.  **Technology:** Use only HTML5, CSS3, and Vanilla JavaScript. No external libraries or frameworks.

## 1. Endless Runner (Advanced Dino-style)

```

**Core Mechanics:**
1.  The game displays a player character (a small square) running automatically across a flat ground plane.
2.  Player input: Pressing the SPACE BAR or clicking the screen triggers a jump.
3.  Obstacles (varying width/height rectangles) must spawn randomly from the right edge and move left towards the player.
4.  **Infinite Scaling:** The horizontal speed of the game must increase every 10 seconds, making the game progressively harder.
5.  Collision detection must be implemented: If the player hits an obstacle, the game stops, and the final score (time survived in seconds) is displayed.
6.  The canvas/game area should be clearly defined and centered on the screen.
```

## 3. Reaction Time Challenge (Addictive!)

```

2.  A large, colored target square appears randomly on the screen.
3.  The player must click the target square as quickly as possible.
```
